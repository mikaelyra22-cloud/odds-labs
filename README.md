# Mks LvL — Shadow Sports Analytics

Tableau de bord d'analyse multisports à identité sombre violette, pour les paris du jour et du lendemain.

## Publication

Dans GitHub, rendre le dépôt public si nécessaire, puis activer **Settings → Pages → Build and deployment → Source : GitHub Actions**. Déclencher le workflow "Publier Mks LvL" si besoin.

Adresse prévue : https://mikaelyra22-cloud.github.io/odds-labs/

## Mode de fonctionnement

Le site est actuellement en **mode démonstration**. Aucun accès aux cotes Winamax en direct, aux statistiques vérifiées ou au compte Winamax n'est inclus. Ne jamais utiliser des exemples fictifs comme des pronostics réels. Aucune mise n'est placée automatiquement. La collecte et l'analyse quotidiennes nécessitent une API de cotes et des données statistiques fiables distinctes. Ne jamais publier une clé API dans ce dépôt public.
